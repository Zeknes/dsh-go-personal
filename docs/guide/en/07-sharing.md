# Local export and sharing

Export a conversation as a file or text, and send files using the system share sheet. This app does not create public share links or image share cards.

Tap `Share` under an AI reply, touch and hold a conversation in the list, or choose **Share** from a delivered file's menu.

1. Select **This reply**, **Selected** messages, or the **Entire chat**. Adjust a selection as needed.
2. Choose whether to include thinking, tool calls, and images.
3. Choose **File** or **Text**. File formats include a `.dshgo` backup, an offline web page, and Markdown; save it to Downloads or use system sharing.

Conversation files and web pages have a 4 MB limit. Select less or choose Markdown if the limit is exceeded. Export masks keys, tokens and passwords in URLs, and replaces home directory usernames with `~`. Recipients can still read the exported content, so check it before sending.

Configurations and plugins can also be exported to local files; choose recipients yourself when using system sharing.
